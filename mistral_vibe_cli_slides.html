概要

Mistral AIの2025年12月発表

  • Devstral 2: オープンソースのコーディング特化AIモデル
  • Mistral Vibe CLI: コマンドライン上のコーディングエージェント
  • Mistral 3: オープンソースのマルチモーダルモデルファミリー
  • Mistral OCR 3: 次世代の文書処理モデル

ポイント: 2025年12月はMistral AIにとって転換点となる月。特にDevstral 2とVibe CLIの発表は、オープンソースのコーディングエージェント分野に大きなインパクトを与える。

Mistral Vibe CLIの特徴

コアコンセプト

  • コマンドライン上のコーディングアシスタント
  • 自然言語でコードベースを操作
  • プロジェクト認識: 自動的にプロジェクト構造とGitステータスを分析
  • ツールセット: ファイル操作、コード検索、バージョン管理、コマンド実行

主な機能

  1. インタラクティブチャット
  2. 強力なツールセット
  3. プロジェクト認識
  4. 高度なCLI体験
  5. 高いカスタマイズ性

ツールセット

組み込みツール

ツール 説明
read_file ファイルの読み取り
write_file ファイルの書き込み
search_replace ファイル内の置換
bash シェルコマンド実行
grep コード検索 (ripgrepサポート)
ask_user_question ユーザーへの質問
task タスクのサブエージェントへの委譲

インストール方法

1. 一行インストール (推奨)

# LinuxとmacOS
curl -LsSf https://mistral.ai/vibe/install.sh | bash
# Windows (PowerShell)
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex" uv tool install mistral-vibe

2. uvを使ったインストール

uv tool install mistral-vibe

3. pipを使ったインストール

pip install mistral-vibe

注意: Windowsはサポートされているが、公式にはUNIX環境をターゲットとしている。

主な機能

1. インタラクティブモード

cd /path/to/your/project
vibe

2. プログラムモード (非インタラクティブ)

vibe --prompt "リファクタリングを実行してください"

オプション

  • --max-turns N: 最大ターン数
  • --max-price DOLLARS: 最大コスト制限
  • --max-tokens N: 最大トークン数
  • --output FORMAT: 出力形式 (text/json/streaming)

組み込みエージェント

エージェント 説明
default 標準エージェント。ツール実行に承認が必要
plan 読み取り専用。安全なツールは自動承認
accept-edits ファイル編集のみ自動承認
auto-approve 全てのツールを自動承認 (注意して使用)
lean インストールされたエージェントのみ
# 使用方法
vibe --agent plan

利用シーン

1. コードの探索と理解

ユースケース: 新しいプロジェクトを理解する

コマンド: vibe "このプロジェクトのアーキテクチャを説明して"

利点: 自動的にプロジェクト構造を分析

2. コードのリファクタリング

ユースケース: 関数やモジュールのリファクタリング

コマンド: vibe "main.pyのmain関数をモジュール化して"

利点: 自然言語で指示可能

3. バグの修正

ユースケース: 特定のバグを修正

コマンド: vibe "このエラーを修正して: [エラーメッセージ]"

利点: コードベース全体を分析して修正

Mistral Vibe CLIの優位点

  1. オープンソース: Apache 2.0ライセンスで自由に使用・改変可能
  2. 高いコスト効率: Devstral 2モデルはClaude Sonnetより7倍のコスト効率
  3. 豊富な機能セット: 豊富な組み込みツール
  4. 高いカスタマイズ性: 設定ファイルで細かく調整可能
  5. プロジェクト認識: 自動的にプロジェクト構造を理解
  6. サブエージェント: タスクを分割して並列処理

課題

  • Windowsサポート: 公式にはUNIX環境をターゲット
  • モデル要求: Devstral 2はH100 GPU 4基を要求
  • 新しさ: 2025年12月発表のため、コミュニティがまだ成熟していない
