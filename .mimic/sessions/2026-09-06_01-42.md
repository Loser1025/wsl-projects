## すぐに実践できる手順（環境変数編）

一番手軽に始められるのは **環境変数 `GOOGLE_APPLICATION_CREDENTIALS`** の使い分けです。

1. **認証ファイルの用意**  
   2つのサービスアカウントキー JSON フイルをプロジェクト内に配置します（例: `~/keys/account-a.json`, `~/keys/account-b.json`）。

2. **シェルのプロファイル（`.bashrc` または `.zshrc`）にエイリアスを登録**  
   ```bash
   # アカウント A 用のエイリアス
   alias start-mcp-a="export GOOGLE_APPLICATION_CREDENTIALS=~/keys/account-a.json && python3 -m multi_bq_mcp.stdio"

   # アカウント B 用のエイリアス
   alias start-mcp-b="export GOOGLE_APPLICATION_CREDENTIALS=~/keys/account-b.json && python3 -m multi_bq_mcp.stdio"
   ```
   必要に応じ `bq-mcp-package/server.py` にも置き換えてください。

3. **利用時**  
   ターミナルで `start-mcp-a` または `start-mcp-b` を実行するだけで、それぞれのアカウントが有効になります。

## `bq` CLI プロファイルを使う場合

すでに `bq` コマンドでプロファイルを使っているなら、こちらもスムーズです。

1. **プロファイルの定義**  
   ```bash
   mkdir -p ~/.config/gcloud/bigquery
   # プロファイル A 用
   cat > ~/.config/gcloud/bigquery/profile-a.json <<'EOF'
   {
     "credential_path": "~/keys/account-a.json",
     "default_project": "my-project-a"
   }
   EOF

   # プロファイル B 用
   cat > ~/.config/gcloud/bigquery/profile-b.json <<'EOF'
   {
     "credential_path": "~/keys/account-b.json",
     "default_project": "my-project-b"
   }
   EOF
   ```

2. **環境変数でプロファイルを指定**  
   ```bash
   export BIGQUERY_CONFIG=~/.config/gcloud/bigquery/profile-a.json
   # またはコマンド直付け
   bq --config_name=profile-a ls
   ```

3. **MCP 起動時**  
   `BIGQUERY_CONFIG` が設定されていると、MCP 内部の `google.auth.default()` などがそのプロファイルを自動で読み込みます（パッケージによるますが、大抵は環境変数を拾います）。

## どの方法がベスト？

- **とにかく簡単に始めたい** → 環境変数 + エイリアス
- **すでに `bq` プロファイルを使っている** → `BIGQUERY_CONFIG` 環境変数
- **MCP ごとに異なるライブラリを使っている** → 使用しているパッケージのドキュメントで「credential path 引数」があるか確認
