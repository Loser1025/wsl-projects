Critical

Critical APIキーのハードコード

APIキー・認証情報がコード内にプレーンテキストで埋め込まれており、リポジトリに含まれることで第三者に漏洩するリスクがあります。

関連ファイル: test_drive_link.js, list_models.js, list_models_rest.js, test_gemini_api.js

Critical 機密情報の存在リスク

サーバーログファイルや環境変数ファイルがプロジェクト内に存在し、誤って配布・共有される危険性があります。

関連ファイル: server.log, .env.local

※ 本レポートには機密情報の内容・APIキーの値は一切含まれておりません。

High

High XSS リスク — innerHTML への AI 生成文字列挿入

AI からのレスポンスを innerHTML に直接挿入して表示しています。レスポンスに悪意あるスクリプトが含まれると、ユーザーブラウザで任意の JavaScript が実行される可能性があります。

関連ファイル: public/js/app.js
修正方針: textContent または createElement/DOM API を使用し、innerHTML 使用箇所を削減してください。描画前にサニティズ（DOMPurify など）を適用することも有効です。

High AI レスポンス全文のログ保存・コンソール出力

parseResponse() が AI から返されたレスポンス全文を debug-responses/ ディレクトリにファイル保存し、同時にコンソールにも詳細ログを出力しています。これにより、分析対象の動画内容や AI の判断結果が意図せず永続化・漏洩する危険性があります。

関連ファイル: api/index.js — parseResponse() 関数
修正方針: 本番環境では debug-responses/ への保存と詳細なレスポンスログ出力を無効化してください。process.env.NODE_ENV などで環境を判定し、本番ではメタ情報のみ出力するようにしてください。

High Google Drive 一時ファイルのパス衝突リスク

Google Drive からダウンロードした動画を /tmp/drive_${Date.now()}.mp4 に保存していますが、同時複数のリクエストが来た場合、同じタイムスタンプになりファイルが上書きされる可能性があります。また、パッと見で内容が推測しやすいパス名です。

関連ファイル: api/index.js — Drive ダウンロード処理
修正方針: fs.mkdtempSync(path.join(os.tmpdir(), 'drive-')) で一意なディレクトリを作成し、その中に保存するか、UUID ベースのファイル名を使用してください。

Medium

Medium Gemini API キー不足・認証エラー時の HTTP 500

APIキーの設定不足や認証エラーが発生しても、レスポンスの HTTP ステータスが 500 Internal Server Error となり、エラー種別が区別できません。エラーハンドリングが不十分です。

関連ファイル: api/index.js
修正方針: 401 Unauthorized、503 Service Unavailable、502 Bad Gateway など、エラーの種類に応じて適切な HTTP ステータスコードを返すようにしてください。

Medium Google Drive URL 処理・MIME タイプ固定

Google Drive の確認ページ処理が不完全で、mime が常に video/mp4 にハードコードされています。実際のファイル形式と異なる場合、後続処理で問題が発生します。

関連ファイル: api/index.js
修正方針: Google Drive API のメタデータ取得機能で実際の MIME タイプを確認するか、Content-Type ヘッダーで検証してください。またファイルサイズ上限のチェックも追加してください。

Medium parseResponse() の error 情報がフロンドエンドに伝わらない

parseResponse() で error=true が検出された場合、フロントエンドにエラー内容が明示的に表示されず、ユーザーが問題を認識しにくい状態です。

関連ファイル: api/index.js (バックエンド), public/js/app.js (フロントエンド)
修正方針: エラーの種類・原因をフロントエンドに JSON で返し、ユーザーが理解できるメッセージで表示してください。

Medium test_compress_and_send.html が未定義関数を呼び出し

テスト用の HTML ファイルが、実装されていない compressAndSendToGemini() 関数を呼び出しています。デプロイに含まれているとユーザーがアクセスした際にエラーで停止します。

関連ファイル: public/test_compress_and_send.html
修正方針: テスト用ファイルをデプロイ対象から除外するか、実装と整合するように修正してください。

Low

Low ルート index.html と public/index.html の不一致

ルート直下の index.html がアップロード UI 付きで public/index.html と内容が異なっている（stale）状態です。どちらが実際に使われるか不明確です。

関連ファイル: index.html (ルート), public/index.html
修正方針: 不要なファイルを削除するか、デプロイ設定で正しいエントリポイントを明示してください。

Low Debug ログ・console.log の多さ

コードベース全体で console.log() や console.error() が多数使用されており、本番環境で機密情報が漏洩するリスクがあります。

関連ファイル: api/index.js, public/js/app.js
修正方針: 本番では出力を抑制するロガーに置き換え、ログレベルで制御できるようにしてください。

Low Promise.race タイムアウトで元リクエストをキャンセルしない

タイムアウト制御用の Promise.race で元の Gemini API リクエストをキャンセルできておらず、タイムアウト後もバックグラウンドで処理が継続しています。Vercel Serverless の実行時間制限を超過する可能性があります。

関連ファイル: api/index.js
修正方針: AbortController を使用してタイムアウト時にリクエストを明示的にキャンセルしてください。

5. 結論

総合評価: ⚠️ 実運用には修正が必要

本プロジェクトの全対象ファイルに対し node -c による構文チェックを実施したところ、構エラーは一切検出されませんでした。また、ローカルサーバー起動後 /api/status が HTTP 200 で正常応答することを確認し、基本的な動作は問題ありません。

しかし、静的解析およびコードレビューの結果、以下の実運用上のリスクが明らかになりました:

  • 機密情報漏洩リスク — APIキーのハードコード、server.log / .env.local の存在、AI レスポンス全文のログ保存
  • XSS 脆弱性リスク — AI 生成文字列の innerHTML への直接挿入
  • 一時ファイル管理リスク — Google Drive ダウンロードパスの同時実行衝突

特に Critical および High の findings は、本番デプロイ前に必ず修正してください。APIキーは直ちにローテーション（再発行）し、コードから削除することを強く推奨します。

本レポートは内部監査目的で作成されました。機密情報（APIキーの値、ログ内容、環境変数値）は含まれておりません。
