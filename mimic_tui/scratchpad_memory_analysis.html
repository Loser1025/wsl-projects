Mimic TUI: セッション内の記憶維持・コンテキスト管理ロジック

概要

Mimic TUI は、セッション内でエージェントの記憶やコンテキストを維持するために、スクラッチパッドと呼ばれる仕組みを使用しています。 この仕組みは、主に utils.py で定義され、スレッドセーフな方法で情報を保持・更新します。

スクラッチパッドの仕組み

1. スクラッチパッドの定義

スクラッチパッドは、グローバル変数 _current_scratchpad として定義され、初期値は「【現在の進捗】タスクを開始しました。」です。 スレッドセーフな操作を保証するために、threading.Lock が使用されます。 

_current_scratchpad: str = "【現在の進捗】タスクを開始しました。"
_scratchpad_lock = threading.Lock()

2. スクラッチパッドの操作関数

スクラッチパッドの内容を取得・更新するための関数が提供されています。

関数名 説明 コード
get_scratchpad() スクラッチパッドの内容を取得します。 
def get_scratchpad() -> str:
    with _scratchpad_lock:
        return _current_scratchpad
set_scratchpad(text: str) スクラッチパッドの内容を更新します。 
def set_scratchpad(text: str) -> None:
    global _current_scratchpad
    with _scratchpad_lock:
        _current_scratchpad = text

スクラッチパッドの利用例

1. エージェントの自己記憶

エージェントは、セッション内でスクラッチパッドを使用して自己記憶を維持します。 例えば、agent.py では、スクラッチパッドの内容を表示するために get_scratchpad() が使用されています。 

--- [エージェントの自己記憶（Scratchpad）] ---
{get_scratchpad()}
--- [Scratchpad ここまで] ---

2. コマンドによる操作

commands.py では、scratchpad コマンドが定義されており、ユーザーがスクラッチパッドの内容を表示できます。 

@cmd_registry.register("scratchpad", "スクラッチパッドの現在の内容を表示")
def cmd_scratchpad(agent: OpenRouterAgent, args: str):
    safe_print(C.yellow("  ┌─ Scratchpad ──────────────────────────────────────"))
    for line in get_scratchpad().splitlines():
        safe_print(f"  │ {line}")

3. ツールによる更新

tools.py では、update_scratchpad というツールが定義されており、エージェントがスクラッチパッドの内容を更新できます。 

def update_scratchpad(content: str) -> str:
    set_scratchpad(content)
    return "Scratchpad updated."

まとめ

Mimic TUI のセッション内の記憶維持・コンテキスト管理は、スクラッチパッドを中心に構築されています。 スレッドセーフな操作が保証され、エージェントやユーザーが自由に内容を取得・更新できます。
