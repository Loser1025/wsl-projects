# ポケモンカード図鑑 · 成果物と設計書

作成日：2026年9月20日

## 最初に見るもの

- **画面を見る**：`確認画面を開く.cmd` をダブルクリックしてください。保存済みの確認表を開きます。Pythonやサーバーの起動は不要です。
- **設計を読む**：`docs/設計書.md`。
- **元の要件を読む**：`docs/当初の実装要件.txt`。ユーザー提供文書をそのまま保存しています。
- **プログラムを検証する**：`app/検証する.cmd`。テストと架空データの取り込みを再実行します。

## 現在の状態

フェーズ1の解析・保存処理を作成し、自動テスト23件が成功しています。架空HTMLから5件を解析し、50円以上の4件をSQLiteに保存しました。実際の商品データ・相場は含まれていません。

実サイトではカテゴリページの取得がHTTP403となり、実パックの取得・目視照合・連続アクセス試験は未完了です。完成版の図鑑画面、米国相場、所持管理画面、定時更新は未実装です。

このフォルダーは既存成果物のコピーです。元の実装と表示中のローカル画面はそのまま利用できます。保存済みレポート中の絶対パスは、実行当時の元フォルダーを指します。現在の同梱DBは `app/data/demo/demo.sqlite3` です。

`app/検証する.cmd` はこのPCのPythonを優先して使用します。別のPCではPython 3.10以降をインストールし、`app/README.md` の手順で実行してください。
