## 動かし方

Python 3.10以降。外部ライブラリ不要です。このPCでは `検証する.cmd` をダブルクリックすると、テスト→架空HTML取り込み→確認表表示を実行します。ネットワーク接続はありません。

他のPCでは、このフォルダーで次を実行できます。

```powershell
python -m unittest -v
python pilot.py demo
```

結果は `data/demo/` の次のファイルです。

- `demo.sqlite3`：架空データ専用DB。本番相場として使用しないでください。
- `review.html`：名前・レアリティ・型番・価格・在庫の目視確認表。ブラウザで開けます。
- `report.json`：件数、欠損、解析を保留した商品、フェーズの状態。

## 今回実装した内容

- PC版の商品リンク単位でタイトル・販売価格・在庫を解析。
- 全角/半角、大文字/小文字、型番の先頭ゼロを正規化。元レアリティも保存。
- 型番欠損、未知レアリティ、状態違い、複数価格、同一キー衝突を自動決定せず記録。
- 50円以上で初収録。一度収録したカードは50円未満になっても保持し `is_active=0`。所持情報・初収録日・価格履歴を保持。
- 新規49円以下は未収録。在庫0でも掲載価格は保存。在庫欠損はNULLとし警告。
- 取得失敗・解析0件ではDBを書き換えない。ページにないカードを対象外にしない。
- 2秒間隔、robots.txt確認、最大40リクエスト・20ページ、403/429等で停止、リダイレクト追従なし。
- パイロット内では全ページ取得後に保存。途中失敗で一部を最新データとして保存しない。
- 取得日時はUTC。取り込みHTMLでは元の取得時刻が不明なため、取り込み日時を記録。
- 外部画像は取得・表示しないため、直リンクなし。画像保存は未実装。

## 実データで再開する方法

サイト運営側の許可された接続方法（このツールのUser-Agent/IPの扱いなど）が整った後に使います。現在の403が解消したとは確認できていません。

```powershell
python pilot.py discover
```

成功すれば `data/discover/report.json` にサイト内のリンクから抽出したカテゴリ候補が出ます。候補はパック以外のカテゴリも含むため、正式なパック名と対象を目視で確認します。IDを推測・捏造していません。

```powershell
python pilot.py fetch --group-id 実際の数字ID --pack-name "確認した正式パック名"
```

`data/fetch/requests.jsonl` にHTTP状況を追記し、保存HTMLと解析表を同じフォルダーに残します。403等が出たら終了します。ブロックを避けるためのUA偽装やプロキシ変更は実装していません。

運営から提供された、または利用許可のある保存済みPC版HTMLなら、ネットワークなしでも試せます。UTF-8で保存された同一パックの全ページを指定してください。

```powershell
python pilot.py import-html --group-id 実際の数字ID --pack-name "正式パック名" page1.html page2.html
```

HTMLの完全性と保存時点は自動では証明できません。実HTMLによる目視照合が必要です。画像データはHTMLから取り込みません。

1. 許可された接続経路で実際の1パックの全ページを取得する。
2. 実HTMLに合わせて解析箇所を調整し、画面と名前・型番・レアリティ・価格・在庫・総件数を照合する。

5. 完了の根拠を記録してからフェーズ2のブラウザ画面へ進む。
